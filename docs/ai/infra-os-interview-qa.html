Bash and Shell

How do you make a Bash script stop if a command fails?

Use set -e to stop on a command failure, and often set -euo pipefail for stricter behavior. -u fails on undefined variables, and pipefail makes a pipeline fail if any command in it fails.

What does echo "${1:-yay}" do?

It prints the first positional argument if one was provided and is not empty. Otherwise, it prints yay.

What does echo $0 print?

It prints the name of the current shell or script. In a script, it is usually the script path or script name.

What does echo $? print?

It prints the exit status of the previous command. 0 usually means success, and a non-zero value means some kind of failure.

What does echo $$ print?

It prints the PID of the current shell process. In a script, that is the PID of the shell running the script.

What does echo $# print?

It prints the number of positional arguments passed to the script or function.

What is $@?

$@ expands to all positional arguments, preserving them as separate arguments when quoted as "$@". That is why "$@" is the safe way to forward arguments.

Explain Bash conditionals and how to use them.

Conditionals let you run code only if a test is true, usually with if, elif, and else. Common tests include string checks, numeric comparisons, file checks, and command exit status.
Example: if [ -f /etc/passwd ]; then echo "file exists"; elif [ "$count" -gt 10 ]; then echo "count is high"; else echo "fallback"; fi

How do you negate a conditional in shell scripting?

Use ! before the test or command. It flips success to failure and failure to success.
Example: if ! grep -q root /etc/passwd; then echo "root not found"; fi

What is a loop in Bash? What loop types are common?

A loop repeats a block of code until a condition changes or for each item in a list. The common types are for, while, and until.

What does ${var//*.} do?

It replaces all matches of the pattern *. with an empty string. In practice, because *. is greedy in shell pattern matching, it usually removes everything up to and including the last dot.

What does ${var%.*} do?

It removes the shortest suffix that matches .* from the end of the variable. It is commonly used to strip a file extension.

How do you generate an 8-digit random number in Bash?

One simple way is printf "%08d\n" $(( RANDOM * RANDOM % 100000000 )). This is fine for basic scripting, but not for security-sensitive randomness.

Any other ways to generate an 8-digit random number?

Yes, for better randomness you can use /dev/urandom, shuf, or openssl rand. Example: shuf -i 10000000-99999999 -n 1.

Give some Bash best practices.

Use set -euo pipefail, quote variables, prefer $(...) over backticks, and use functions for repeated logic. Also validate inputs, use meaningful variable names, and run shellcheck on scripts.

What is the ternary operator, and how do you use it in Bash?

Bash does not have a real ternary operator like some programming languages. The closest equivalent is using if or short-circuit operators like condition && value1 || value2, but if is usually safer and clearer.

What does diff <(ls /tmp) <(ls /var/tmp) do?

It compares the output of ls /tmp and ls /var/tmp without creating temporary files. <(...) is process substitution, which exposes command output as a file-like input to diff.

What do you use for testing shell scripts?

A common choice is bats, which is Bash Automated Testing System. For linting and catching common mistakes, shellcheck is also widely used.

File Descriptors, Open Files, and lsof

What is a file descriptor?

A file descriptor is a small integer that a process uses to refer to an open file, socket, pipe, or similar resource. Standard input, output, and error are usually descriptors 0, 1, and 2.
To list the file descriptors for the current shell process, use ls -l /proc/$$/fd.
Example output:
$ ls -l /proc/$$/fd
total 0
lrwx------ 1 omer omer 64 May 11 10:37 0 -> /dev/pts/0
lrwx------ 1 omer omer 64 May 11 10:37 1 -> /dev/pts/0
lrwx------ 1 omer omer 64 May 11 10:37 2 -> /dev/pts/0
lrwx------ 1 omer omer 64 May 11 10:37 255 -> /dev/pts/0

Summarize file descriptors in simple terms.

A file descriptor is the handle a process uses to access open I/O resources. It lets the kernel track what the process is reading from or writing to.

What does lsof do, and what is it used for?

lsof lists open files and the processes using them.
In Linux, “files” can also mean sockets, pipes, devices, directories, and other resources, not just regular files on disk.
It is useful for debugging things like file locks, deleted-but-still-open files, and network sockets.

Can you also use lsof for network connections?

Yes. lsof -i shows processes and the network sockets they have open.

What can lsof -p $$ show about file descriptors?

lsof -p $$ lists the open files for the current shell process.
Example output:
COMMAND PID USER FD TYPE DEVICE SIZE/OFF NODE NAME
bash 1297 alex cwd DIR 8,48 4096 579964 /home/alex
bash 1297 alex rtd DIR 8,48 4096 2 /
bash 1297 alex txt REG 8,48 1396520 489029 /usr/bin/bash
bash 1297 alex 0u CHR 136,0 0t0 3 /dev/pts/0
bash 1297 alex 1u CHR 136,0 0t0 3 /dev/pts/0
bash 1297 alex 2u CHR 136,0 0t0 3 /dev/pts/0
bash 1297 alex 255u CHR 136,0 0t0 3 /dev/pts/0

From this we can derive:
  • cwd = current working directory, /home/alex
  • rtd = root directory, /
  • txt = the executable file, /usr/bin/bash
  • 0 = stdin
  • 1 = stdout
  • 2 = stderr
  • 255 = internal Bash file descriptor
The terminal-related descriptors all point to /dev/pts/0.
That means the shell is reading input from the terminal and writing normal output and errors back to the same terminal.

Why are open files used for discovering network connections?

Because sockets are represented as file descriptors inside the process. That means a network connection appears as an open file-like object from the process perspective.

Processes, Signals, and System Basics

What is dmesg, and what is it used for?

dmesg shows messages from the kernel ring buffer, which is an in-memory log area used by the Linux kernel.
It is mainly used for low-level troubleshooting: boot messages, hardware detection, driver errors, disk I/O problems, USB events, network interface changes, OOM kills, and kernel warnings.
Because it is a ring buffer, old messages can be overwritten when the buffer fills up.

What are common dmesg commands for troubleshooting?

Common commands include dmesg | tail, dmesg -T | tail, dmesg -w, and sudo dmesg.
dmesg -T shows human-readable timestamps. dmesg -w follows new kernel messages live, similar to tail -f. Some systems require sudo dmesg because kernel logs can expose sensitive system details.

How can dmesg help during RCA?

dmesg helps identify kernel-level events around the time of an incident.
For RCA, look for errors, warnings, resets, timeouts, OOM kills, disk I/O errors, network interface flaps, driver failures, and hardware messages.
Useful command: dmesg -T | grep -iE "error|fail|warn|reset|timeout|oom|killed"

A server became slow and processes disappeared. How can dmesg help?

Check whether the kernel OOM killer terminated processes because the system ran out of memory.
Use dmesg -T | grep -iE "oom|out of memory|killed process".
If you see killed-process messages, the likely root cause is memory pressure, not an application randomly crashing.

An application reports disk errors. How can dmesg help?

dmesg can show storage-level problems that application logs may not explain: I/O errors, filesystem warnings, disk resets, NVMe/SCSI/SATA timeouts, or device disconnects.
Use dmesg -T | grep -iE "I/O error|nvme|sda|ext4|xfs|reset|timeout".
If those messages appear around the incident time, the root cause may be the disk, filesystem, VM volume, or storage infrastructure.

A network service went down, but app logs look normal. How can dmesg help?

dmesg can show whether the network interface went down, the link flapped, firmware failed, or the NIC driver reset.
Use dmesg -T | grep -iE "eth|ens|enp|link down|link up|firmware|driver|reset".
If the kernel shows link events during the outage, the issue may be below the application layer.

A machine rebooted unexpectedly. Is dmesg enough?

Usually no.
After reboot, dmesg mostly shows messages from the current boot. For previous boot kernel logs, use journalctl -k -b -1.
That is usually more useful for RCA after a crash or unexpected reboot.

A container was killed unexpectedly. Can dmesg help?

Yes, if the container process was killed by the host kernel because of memory pressure.
Use dmesg -T | grep -iE "oom|killed process|memory cgroup".
If memory cgroup messages appear, the cause may be a container memory limit or host memory pressure.

How do you check the current load average?

Use uptime, w, or cat /proc/loadavg. Load average shows the average number of runnable or uninterruptible tasks over 1, 5, and 15 minutes.

How do you check process usage?

Use top, htop, ps, or pidstat. They show CPU, memory, state, and other per-process details.

How do you check free memory and memory usage by process?

Use free -h for overall memory and top, htop, ps aux --sort=-%mem, or smem for per-process usage. smem is useful because it can show proportional set size, which is often more realistic than RSS alone.

How do you check TCP stats?

Use ss -s, netstat -s, or inspect /proc/net/snmp. These show connection counters, retransmissions, resets, and protocol-level stats.

How can you find how much memory a specific process consumes?

Use ps -o pid,comm,rss,vsz -p <pid>, pmap -x <pid>, or check /proc/<pid>/status. RSS is resident memory in RAM, while VSZ is the virtual memory size.

What does kill 0 do?

kill 0 sends the default signal, usually SIGTERM, to all processes in the current process group. It is not the same as kill -0 <PID>.

What does kill -0 <PID> do?

It does not actually kill the process. It checks whether the process exists and whether you have permission to send it signals.

What are the possible states of a process in Linux?

Common states are running or runnable (R), sleeping (S), uninterruptible sleep usually waiting on I/O (D), stopped (T), zombie (Z), and sometimes idle or dead states internally. Tools like ps show the main visible ones.

How do you kill a process in D state?

Usually you cannot kill it immediately because D means uninterruptible sleep, often waiting in the kernel for I/O. You usually have to fix the underlying stuck I/O, device, or mount issue, or reboot if it cannot recover.

What is WCHAN ?

WCHAN stands for wait channel. It shows the kernel function where a sleeping process is waiting.

What does echo t do?

By itself, it just prints the letter t to standard output. It does nothing special unless redirected somewhere meaningful.

What happens when echoing t to WCHAN?

Normally nothing useful, because /proc/<pid>/wchan is a read-only file. You cannot trigger stack dumps by writing to WCHAN.

What about echo t > /proc/PID/wchan?

That will fail because wchan is not meant to be written to. You may be thinking of echo t > /proc/sysrq-trigger, which asks the kernel to dump task backtraces.

What is a zombie process?

A zombie is a process that has already finished execution, but its parent has not yet reaped its exit status with wait(). It is not running anymore, but it still has a process table entry.

Can you say a zombie "finished running but hasn't exited"?

Not really. A zombie has already exited, but it has not been reaped by its parent yet.

How do you find processes owned by a certain user?

Use ps -u username or pgrep -u username. You can also filter ps aux output with grep, but the dedicated options are cleaner.

How do you find Java processes?

Use pgrep java, ps aux | grep java, or jps if the JDK tools are installed. jps is especially useful for Java-specific process listing.

How do you find zombie processes?

Use ps aux | awk '$8 ~ /^Z/' or ps -el | grep ' Z '. The process state Z indicates a zombie.

How are processes created?

Traditionally a process is created with fork(), which duplicates the current process, and then often exec() replaces the child with a new program. Modern Linux also uses clone() for more flexible process and thread creation.

How do you change process priority?

Use nice to start a process with a chosen niceness, or renice to change it for a running process. Lower nice values mean higher priority, but raising priority usually requires extra privileges.

How is a network connection established and terminated?

A TCP connection is created through the three-way handshake: SYN, SYN-ACK, ACK. It is usually terminated with FIN and ACK packets on each side, or abruptly with RST.

What is a socket?

A socket is an endpoint that software uses to send and receive data over a network, or sometimes between processes on the same machine.

Does a network connection use a socket?

Yes. A socket is the OS abstraction a process uses to send and receive network data, and the kernel uses it to track the connection state.

What is the difference between strace and ltrace?

strace traces system calls and signals, so it shows how a program talks to the kernel. ltrace traces library calls, so it shows calls to shared libraries like libc.

How do you find all .yml files and replace 1 with 2 in each file?

A common way is find . -name '*.yml' -type f -exec sed -i 's/1/2/g' {} +. In real work, be careful because blind replacement may change values you did not intend to touch.

You run ls and get /lib/ld-linux-armhf.so.3: no such file or directory. What is the problem?

That usually means the binary was built for a different architecture or expects a dynamic loader that is missing. For example, an ARM binary is being run on a system that does not have the required ARM runtime.

What is NTP and what is it used for?

NTP is the Network Time Protocol. It keeps system clocks synchronized, which is important for logs, security, distributed systems, and scheduling.

How do you check NTP configuration?

Check the service in use, such as chronyd, ntpd, or systemd-timesyncd, and inspect its config files like /etc/chrony.conf. You can also use timedatectl, chronyc sources, or ntpq -p depending on the service.

How can the kernel promise more memory than it can actually provide?

That is called memory overcommit. Linux can allow allocations based on the assumption that not every process will use all requested memory at the same time.

Can Linux overcommit more than available virtual memory?

It can overcommit beyond physical RAM and swap, depending on the overcommit policy. The actual behavior is controlled by /proc/sys/vm/overcommit_memory and related settings.

What is chroot, and when would you use it?

chroot changes the apparent root directory for a process. It can be used for recovery, testing, or isolation, but it is not strong security isolation by itself.

Give a chroot example.

A rescue environment can mount a broken system under /mnt and run chroot /mnt to repair it as if booted into that system. It is also used when building packages or creating minimal sandboxed environments.

What is the chroot syntax?

The common form is chroot NEWROOT [COMMAND [ARGS...]]. If no command is provided, it usually starts a shell inside that new root.

What is SELinux?

SELinux is a Linux security framework that enforces mandatory access control policies. It can restrict what processes may access, even if traditional UNIX permissions would allow it.

What is Kerberos?

Kerberos is a network authentication protocol based on tickets. It lets users and services authenticate securely without repeatedly sending passwords over the network.

What is nftables?

nftables is the modern Linux packet filtering and firewall framework that replaces older tools like many iptables setups. It provides a more unified and flexible rule system.

What is the nftables syntax like?

It uses tables, chains, and rules, for example: nft add rule inet filter input tcp dport 22 accept. The syntax is more structured than classic iptables.

What does iptables v1.8.7 (nf_tables) mean?

It means the iptables command is using the nf_tables backend under the hood. So the old command-line tool is translating rules to the newer kernel framework.

What is firewalld responsible for?

firewalld is a firewall management service that dynamically manages rules, zones, and services. It provides a higher-level way to control firewall policy without editing raw rules directly.

What is server hardening? What is the process?

Server hardening means reducing the attack surface and tightening security settings. In practice that means patching, disabling unused services, locking down access, configuring logging and monitoring, least privilege, and regularly reviewing the system.

Show one way to encode and decode data in Linux.

A common example is Base64. You can encode with echo -n "hello" | base64 and decode with echo "aGVsbG8=" | base64 -d.

What is Base64?

Base64 is an encoding format that represents binary data as printable ASCII text. It is used for compatibility when data needs to pass through systems that expect text. It is not encryption.

What is the benefit of using Base64?

It lets binary data, like images, files, or tokens, be safely stored or transmitted in text-based formats such as email, JSON, or HTTP headers. The tradeoff is that the encoded data is usually about 33% larger.
For URLs, regular Base64 can include characters like +, /, and =, which may need escaping. That’s why Base64URL exists: it uses URL-safe characters so the encoded value can be placed in URLs more safely.

Networking Basics

What is BGP?

BGP means Border Gateway Protocol. It is the routing protocol used to exchange routes between large networks, usually between autonomous systems on the internet.
Plainly: BGP helps different networks tell each other, “I know how to reach these IP ranges.”

What is OSPF?

OSPF means Open Shortest Path First. It is an internal routing protocol used inside one organization or network to help routers choose the best path.
It is commonly used inside enterprise networks, data centers, and service provider networks.

What is the main difference between BGP and OSPF?

BGP is usually used between networks. OSPF is usually used inside one network.
BGP focuses more on policy and control: which routes should be advertised, preferred, blocked, or changed.
OSPF focuses more on finding the shortest path inside a known network topology.

When would you use BGP instead of OSPF?

Use BGP when routing between separate networks, cloud environments, ISPs, autonomous systems, or when you need strong routing policy control.
Use OSPF when routing inside one internal network where routers need to automatically learn the topology and choose efficient paths.

What is SDN?

SDN means Software-Defined Networking. It separates the network control plane from the data plane, so network behavior can be controlled by software instead of manually configuring every device one by one.
Plainly: instead of logging into each switch and router manually, software defines how traffic should flow.

What is the difference between the control plane and data plane?

The control plane decides where traffic should go. The data plane actually forwards the packets.
In traditional networking, both often live inside the same physical device. In SDN, the control logic can be centralized or managed by software.

Why is SDN useful?

SDN makes networks easier to automate, change, and manage at scale. It is useful in cloud platforms, data centers, Kubernetes networking, virtual networks, and environments where network policy changes often.

How does SDN relate to Linux bridges, namespaces, and virtual networking?

Linux bridges, veth pairs, namespaces, VXLAN, Open vSwitch, and routing rules can all be building blocks for software-defined networking.
In practice, SDN often means software is creating and managing virtual network paths instead of relying only on physical switches and static manual configuration.

How do you list all network interfaces?

Use ip link or ip addr. ip addr also shows IP addresses, while ip link focuses more on the interface state and link-layer details.

How do you read this interface line: 2: eth0: <BROADCAST,MULTICAST,UP,LOWER_UP> ...?

It means the interface is named eth0, supports broadcast and multicast, is administratively up, and the physical or virtual link is up. mtu 1500 is the maximum transmission unit, and the link/ether line shows the MAC address.

What does ip addr do?

It shows or manages IP addresses assigned to interfaces. It can also show interface state and related details.

What does ip route do?

It shows or manages the routing table. That tells the kernel where to send packets for different destinations.

What does ip link do?

It shows or manages network interfaces at the link layer. You can use it to bring interfaces up or down and inspect link properties.

What does ping do?

It sends ICMP echo requests to test reachability and measure round-trip time. It is a basic connectivity test, not a full application-level test.

What does netstat do?

It shows network connections, routing tables, interface stats, and more. It is older, and ss is usually preferred on modern Linux.

What does traceroute do?

It shows the path packets take to a destination by sending packets with increasing TTL or hop limit values. Each router that decrements TTL to zero sends back a response, revealing the path hop by hop.

How does traceroute work?

It sends packets with gradually increasing TTL values. Each router that drops a packet because TTL reached zero sends back an ICMP message, which reveals that hop.

What part of the TCP header does traceroute modify?

Classic traceroute logic is based on the IP header TTL field, not a TCP header field. TCP-based traceroute still changes TTL in the IP layer.

What is a network namespace, and what is it used for?

A network namespace gives a process its own isolated network stack, including interfaces, routes, firewall rules, and sockets. Containers use this heavily to isolate networking.

How can you turn a Linux server into a router?

Enable IP forwarding and configure routes and, if needed, NAT or firewall rules. For example, set net.ipv4.ip_forward=1 and then configure forwarding rules with nftables or iptables.

What is a virtual IP, and when would you use it?

A virtual IP is an IP address not tied permanently to one physical interface or host. It is commonly used for high availability, failover, load balancers, or service endpoints.

What is the routing table, and how do you view it?

The routing table tells the kernel where to send packets based on destination networks. View it with ip route or the older route -n.

Give examples of routing table entries.

default via 192.168.1.1 dev eth0 means use that gateway for destinations not matched elsewhere. 10.0.0.0/24 dev eth1 means traffic to that subnet goes directly out eth1.

How can you send an HTTP request from your shell?

The most common way is curl, for example curl http://example.com. You can also use tools like wget or nc for raw requests.

What is nc?

nc, or netcat, is a simple tool for reading from and writing to network connections. It is often used for debugging, quick tests, or manual protocol interaction.

How do you use nc to send an HTTP request?

You can connect and type a raw request, for example:
`printf 'GET / HTTP/1.1 Host: example.com
' | nc example.com 80`
This is useful for understanding HTTP at a lower level.

What are packet sniffers, in one sentence?

Packet sniffers capture and inspect network traffic so you can analyze what is happening on the wire.

How do you list active connections?

Use ss -tulpen or ss -an. The older alternative is netstat -tulpen.

How do you trigger neighbor discovery in IPv6?

Usually it happens automatically when the kernel needs to reach a local IPv6 neighbor. You can trigger it by sending traffic, for example with ping6, and inspect the neighbor table with ip -6 neigh.

What does -n usually mean in networking tools?

It usually means "numeric output". That tells the tool not to resolve hostnames, service names, or user names, which makes output faster and more literal.

What is network interface bonding, and how is it done in Linux?

Bonding combines multiple network interfaces into one logical interface for redundancy, load sharing, or both. In Linux it is usually configured with the bonding driver, NetworkManager, or system config files.

What network bonding modes are there?

Common modes include active-backup, balance-rr, balance-xor, broadcast, 802.3ad or LACP, balance-tlb, and balance-alb.
In interviews, active-backup and LACP are the most common to explain.

What is a bridge, and how do you add it in Linux?

A bridge is a virtual Layer 2 switch that forwards frames between interfaces. You can create one with ip link add br0 type bridge, then attach interfaces to it.

Give an example use case for a bridge.

VMs or containers often connect to a Linux bridge so they can share the host's physical network. It is also common in hypervisors and container networking.

What is /etc/resolv.conf used for, and what does it include?

It configures DNS resolution for the system resolver. It commonly contains nameserver, search, and sometimes options lines.

Show an example of /etc/resolv.conf.

A simple example is:
nameserver 8.8.8.8
nameserver 1.1.1.1
search example.local
options timeout:2 attempts:3

What is nameserver for?

It specifies the IP address of a DNS server the resolver should query. Each nameserver line adds another resolver target.

Is nameserver a keyword?

Yes, in the context of /etc/resolv.conf it is a configuration directive or keyword.

What commands can be used for DNS queries or DNS troubleshooting?

Common tools are dig, nslookup, host, resolvectl, and sometimes ping or curl for indirect testing. dig is usually the most informative.

How do you modify a connection with nmcli to use 8.8.8.8 as DNS?

A typical command is nmcli con mod "<connection-name>" ipv4.dns "8.8.8.8". Then apply it with nmcli con up "<connection-name>" or reconnect the interface.

Give common nmcli examples.

Use nmcli con show to list connections, nmcli dev status to show devices, and nmcli con up/down "<name>" to activate or deactivate a connection.
It is basically the CLI for NetworkManager.
\Example output:
$ nmcli dev status
DEVICE TYPE STATE CONNECTION
br-4c3f3d7e7b88 bridge unmanaged --
docker0 bridge unmanaged --
eth0 ethernet unmanaged --
lo loopback unmanaged --

Packaging, Repositories, and Archives

How does software packaging work on Linux?

Software is bundled into packages that contain files, metadata, dependencies, and install scripts. A package manager installs, upgrades, removes, and tracks them through repositories.
Different Linux families use different package formats and tools:
  • Debian/Ubuntu:        .deb packages, managed with apt/dpkg
  • RHEL/CentOS/Fedora:  .rpm packages, managed with dnf/yum/rpm
  • Arch Linux:          .pkg.tar packages, managed with pacman
  • openSUSE:            .rpm packages, managed with zypper/rpm
For daily use, you usually use the higher-level package manager, like apt, dnf, yum, pacman, or zypper, because it handles repositories and dependencies automatically. Tools like dpkg and rpm are lower-level and are mostly used for installing local package files directly.

Explain the RPM spec format

An RPM spec file defines metadata like name, version, release, summary, license, and source, plus build and install instructions. Common sections include %prep, %build, %install, %files, and %changelog.

How do you list the contents of a Debian package without installing it?

For RPM packages use rpm -qlp package.rpm. For Debian packages use dpkg-deb -c package.deb.

(RHEL-based distros) Do you install packages with yum or rpm?

Usually yum or dnf is preferred because it resolves dependencies and works with repositories. rpm installs a package directly but does not handle dependency resolution as conveniently.

How do you know which package a file belongs to, and is it a problem if it belongs to none?

On Debian/Ubuntu, use dpkg -S /path/to/file.
Example: dpkg -S /usr/bin/bash.
On RPM-based systems, use rpm -qf /path/to/file.
If the file is not installed yet but exists in Ubuntu repositories, you can use apt-file search /path/to/file.
If a file belongs to no package, it may have been manually installed, generated locally, created by a script, or left behind after removal. That is not always wrong, but it is worth understanding where it came from.

What is DNF?

DNF = Dandified YUM. It's the newer package manager that replaced YUM on many RPM-based distributions. It provides dependency resolution and repository management like YUM, with improved internals.

How do you find the package that provides /usr/bin/git if it is not installed?

On RPM-based systems use dnf provides /usr/bin/git. On Debian-based systems use apt-file search /usr/bin/git.

What does dpkg -S /bin/bash mean?

It asks which installed package owns /bin/bash. If the output is bash: /bin/bash, that means the file belongs to the bash package.

Where are repositories stored on different distributions?

On Debian and Ubuntu they are usually in /etc/apt/sources.list and /etc/apt/sources.list.d/. On RHEL-like systems they are usually in /etc/yum.repos.d/.

What is an archive, and how do you create one in Linux?

An archive is a bundled collection of files, often created with tar. Example: tar -cvf archive.tar dir/.

What is -f in tar for?

It tells tar that the next argument is the archive file name. Without -f, tar would not know which archive file to read or write.

How do you extract an archive?

For a plain tar archive use tar -xvf archive.tar. For compressed archives use the matching option, such as -z for gzip or -J for xz.

What can you find in /etc/services?

It maps well-known service names to port numbers and protocols. For example, it may define that ssh is 22/tcp.

What do you call a piece of text taken from the full text?

Usually a snippet or an excerpt. In search systems, "snippet" is very common.

You run ssh 127.0.0.1  and get "connection refused". What could be the problem?

Most commonly, the SSH server is not running, not listening on that address or port, or a firewall is blocking it. "Connection refused" usually means the host is reachable but nothing accepted the connection on that port.

How do you print the shared libraries required by a program, and what is it useful for?

Use ldd /path/to/program. It helps with troubleshooting missing dependencies, runtime issues, and understanding how a binary is linked.

What is CUPS?

CUPS = Common UNIX Printing System. It provides printing services, print queues, and printer management on Linux and UNIX-like systems.

List common types of web servers.

Common web servers include Nginx, Apache HTTP Server, Caddy, and LiteSpeed. In application stacks, reverse proxies and app servers often work together.

Users, Identity, and System Info

What is CSAT, and why might it matter in a technical support or DevOps role?

CSAT means Customer Satisfaction Score. It measures how satisfied users or customers are after an interaction, usually through a short survey.
In a technical role, it matters because solving the issue is not the only goal. You also need clear communication, good follow-up, and making the user feel the problem is handled.

What is a superuser or root user? How is it different from regular users?

The root user has UID 0 and can bypass most permission checks. Regular users are restricted by file permissions, capabilities, and policy controls.

How do you add a new user without allowing login?

Create the user with a non-login shell, for example useradd -s /sbin/nologin username or /usr/sbin/nologin depending on the system. That allows the account to exist without interactive shell access.

How do you show the UID of all users?

You can read /etc/passwd or use getent passwd and print the third field. Example: cut -d: -f1,3 /etc/passwd.

What can you do if you forgot the root password?

Typical recovery methods include booting into single-user or rescue mode, editing the bootloader kernel parameters, or dropping into an initramfs recovery shell when available.
From there, an admin can usually mount the root filesystem, reset the password, and reboot.
The exact method depends on the distribution, bootloader setup, whether you have console access, and whether disk encryption, cloud access controls, or security policies are involved.

What is init=/bin/bash?

It is a kernel boot parameter that tells the system to start /bin/bash as PID 1 instead of the normal init system. It is often used for emergency recovery, not for normal operation.

Is init=/bin/bash related to boot log level?

No. It changes which program becomes PID 1, while log level controls how much kernel or boot output is shown.

What does the id command do?

It prints the current user's UID, GID, and group memberships. You can also run id username for another user.

Why might grep $(whoami) /etc/passwd return nothing?

One reason is that the system may use centralized identity sources like LDAP, SSSD, or Active Directory instead of storing the user in local /etc/passwd. In that case getent passwd $(whoami) is a better check.

How can you print BIOS, motherboard, processor, and RAM information?

Use tools like dmidecode, lshw, lscpu, and free or cat /proc/meminfo. dmidecode often requires root because it reads firmware tables.

Namespaces, Virtualization, and Containers

What is a hypervisor?

A hypervisor is software that runs and manages virtual machines. It provides each VM with virtual CPU, memory, disk, and network devices while sharing the real physical hardware underneath.

What is the difference between Type 1 and Type 2 hypervisors?

A Type 1 hypervisor runs directly on the hardware, like VMware ESXi, Hyper-V, or Xen in many setups.
A Type 2 hypervisor runs on top of a normal host operating system, like VirtualBox or VMware Workstation.
KVM is a bit special in wording: Linux with KVM acts as a hypervisor because virtualization support is built into the Linux kernel.

What is QEMU?

QEMU, pronounced “kyoo-em-you”, is an emulator and virtualizer. It can emulate hardware devices and CPU architectures, and it is often used together with KVM to run virtual machines efficiently on Linux.
Without KVM, QEMU can still emulate a machine, but it may be much slower because more work is done in software.

How is KVM related to QEMU?

KVM provides kernel-level virtualization acceleration. QEMU, pronounced “kyoo-em-you”, provides device emulation and VM process management.
Together, QEMU + KVM lets VMs run efficiently while still emulating the hardware devices the guest needs.

What types of namespaces are there in Linux?

The main namespace types are mount, PID, network, UTS, IPC, user, cgroup, and time. They isolate different parts of the system so processes can have separate views.

Is it possible to have a root user with UID 0 in a child user namespace?

Yes. Inside the child user namespace a process can appear as UID 0 even though it is not real root in the parent namespace.

Who has UID 0 in the parent namespace?

Only the real root user in the parent namespace has UID 0 there. Namespace mappings decide how IDs translate between parent and child.

What are time namespaces used for?

Time namespaces let processes see different values for certain clocks, such as boot time or monotonic offsets. They are useful for containers, checkpoint and restore, and testing time-dependent behavior.

What does it mean that processes can use different system time in time namespaces?

It means they can observe different clock values without changing the host's global clock. It is not a full separate wall clock for everything, but it does isolate some time-related views.

What virtualization solutions are available for Linux?

Common options include KVM, Xen, VMware, VirtualBox, QEMU, LXC, and Docker-style containers. Full VMs emulate hardware or expose virtualization features, while containers share the host kernel.

What is KVM?

KVM is Kernel-based Virtual Machine. It turns the Linux kernel into a hypervisor so virtual machines can run efficiently using hardware virtualization support.

What is Libvirt?

Libvirt is a management layer and API for virtualization platforms like KVM and QEMU. It lets you define, start, stop, and inspect VMs consistently.

What is the difference between find and locate?

find searches the live filesystem in real time, so it is accurate but can be slower. locate searches a prebuilt index, so it is fast but may be outdated.

What does awk do, and what is it used for?

awk is a text-processing language designed for line-by-line parsing and field-based operations. It is great for filtering, transforming, and reporting on structured text.

What is a system call? List common ones.

A system call is how a user-space program requests a service from the kernel.
Common ones include open, read, write, close, fork, execve, wait, socket, and mmap.

Why use system calls instead of doing these operations directly?

User-space programs cannot directly perform privileged kernel operations or access hardware safely. System calls provide a controlled, secure interface to kernel services.

How does a program execute a system call?

The program calls a library wrapper or issues a system-call instruction, which switches execution from user mode to kernel mode. The kernel handles the request and returns a result code.

What is the return value of fork()?

In the parent, fork() returns the child's PID. In the child, it returns 0, and on failure it returns -1.

Name one reason fork() can fail.

A common reason is resource exhaustion, such as hitting the process limit or running out of memory. Kernel or cgroup limits can also cause it.

Why do we need wait()?

wait() lets a parent reap the exit status of a child process. It also prevents the child from staying as a zombie.

How does the kernel notify the parent about child termination?

It sends the parent SIGCHLD. The parent can then call wait() or waitpid() to reap the child.

Show an example of using wait().

A simple shell example is:
sleep 1 & pid=$!; wait "$pid"; echo $?
This waits for the background child and then prints its exit code.

True or false: a successful call to exec() never returns.

True. If exec() succeeds, the current process image is replaced, so execution continues in the new program instead of returning.

What is a Linux distribution?

A Linux distribution is a packaged operating system built around the Linux kernel plus user-space tools, package management, defaults, and support policies. Examples include Ubuntu, Debian, Fedora, and RHEL.

What Linux distributions are you familiar with?

A good interview answer is to name the ones you have actually used, for example Ubuntu, Debian, CentOS, Rocky Linux, AlmaLinux, Fedora, or RHEL. The key is to connect them to real experience.

What are the components of a Linux distribution?

A distribution usually includes the kernel, core user-space tools, init system, package manager, libraries, configuration defaults, and repositories. Many also include desktop components or cloud-specific tooling.

Using sed, how do you extract the date from 201.7.19.90 - - [05/Jun/1985:13:42:99 +0000] "GET /site HTTP/1.1" 200 32421?

You can capture the part inside brackets before the first colon, for example: sed -E 's/.*\[([^:]+):.*/\1/'. That would output 05/Jun/1985.

What does sed 's/.*\[//g;s/\].*//g;s/:.*//g' do?

The first substitution removes everything up to [, the second removes everything after ], and the third removes everything from the first : onward. The final result is the date part only, such as 05/Jun/1985.

Break that sed expression up and explain it.

It works in stages: first isolate the bracketed timestamp, then strip the trailing ], then cut off the time part after the date. It is a simple pipeline of text cleanup steps applied by sed.

Under which license is Linux distributed?

The Linux kernel is distributed under GPLv2. Some tools in a distribution may use other licenses, but the kernel itself is GPLv2.

What is User-mode Linux?

User-mode Linux is a port of Linux that runs as a user-space process on top of another Linux system. It was used for experimentation, isolation, and kernel testing.

Why are there different man sections? What is the difference?

Different sections separate different kinds of documentation, like user commands, system calls, library functions, file formats, and admin commands. This avoids name conflicts and organizes documentation by topic.

How do you access a specific man section?

Use man <section> <name>, for example man 3 printf or man 1 printf. The section number tells man which category to open.

What does man -S 3 printf mean?

It asks for printf from section 3, which is usually the C library function documentation.

What does man -S 1 printf mean?

It asks for printf from section 1, which is the user command documentation.

How do you count lines in a file? What about words?

Use wc -l file for lines and wc -w file for words. wc can also show bytes and characters.

What is the difference between man and info?

man is usually shorter and reference-oriented, while info often provides longer, more structured documentation with navigation links. In practice, many admins use man more often.

Explain environment variables. How do you list them?

Environment variables are key-value settings passed from a process to its children. They are often used for paths, locale, configuration, and behavior flags, and you can list them with env, printenv, or export -p.

If x=2 is in /etc/bashrc and x=6 is in ~/.bashrc, what is the value after login?

Usually the later assignment wins, so in a typical Bash startup flow the value would end up as 6 if both files are sourced and no later override happens. The exact order depends on the shell type and distro startup files.

What is a TTY device?

A TTY is a terminal device, originally tied to physical teletype terminals and now used for terminal sessions, pseudo-terminals, and consoles. It represents the text interface a shell or program interacts with.

Are wildcards implemented in user space or kernel space?

Mostly in user space. The shell expands wildcards like * and ? before the command is executed.

Describe three ways to remove a file or its content.

You can delete the file with rm, truncate it with > file or truncate -s 0 file, or replace it by moving or recreating it. Deleting removes the directory entry, while truncating keeps the file inode but clears its content.

What is the difference between a process and a thread?

A process has its own address space and resources, while threads within the same process share memory and many resources. Threads are lighter to create, but they require careful synchronization.

What is a context switch?

A context switch is when the CPU stops running one task and starts running another, saving and restoring state. It is necessary for multitasking but has overhead.

A server has high CPU load, but no process shows high CPU. How is that possible?

The load average also counts tasks in uninterruptible sleep, often waiting on I/O, so load can be high even when CPU usage is not. Another possibility is heavy short-lived kernel activity or sampling timing that misses bursts.

When you run ip a, what is lo and why do we need it?

lo is the loopback interface, usually 127.0.0.1 for IPv4 and ::1 for IPv6. It lets the host communicate with itself for local services, testing, and internal networking.

Why do DNS queries sometimes use loopback?

Because a local DNS resolver, cache, or stub resolver may listen on 127.0.0.1 or ::1. Applications send the query locally, and that local resolver forwards it upstream.

How do you link two network namespaces so they can ping each other?

Create a veth pair, move one end into each namespace, assign IP addresses, and bring the interfaces up. A veth pair acts like a virtual cable between the namespaces.

How does cd - work? How does it know the previous location?

The shell tracks the previous working directory in the OLDPWD environment variable. cd - switches to that saved path.

Where does the word "TeleTYpewriter" come from?

It comes from electromechanical terminals that sent typed characters over communication lines. The abbreviation TTY survived even after modern terminals replaced the old hardware.

What are cgroups?

Control groups are a Linux kernel feature for limiting, accounting for, and isolating resource usage like CPU, memory, and I/O for groups of processes. Containers rely on them heavily.

Explain process descriptor and task structure.

In Linux the kernel keeps a task_struct for each task, which stores scheduling, memory, signal, and state information. "Process descriptor" is a common way to describe that kernel data structure.

How can you see process descriptor information?

Not directly in full form from user space, but much of it is exposed through /proc, ps, top, and tracing tools. Deep inspection usually requires kernel debuggers or source-level knowledge.

How can you make a system call from Bash, like getpid?

Bash itself does not expose arbitrary raw system calls directly. You usually call an external program written in C, Python, Perl, or use shell features that already invoke system calls under the hood, like echo $$ for the shell PID.

Explain kernel threads.

Kernel threads are tasks that run only in kernel space and are created for internal kernel work. They do not have a normal user-space program image.

Do you have an example of a kernel thread?

Examples include kworker, ksoftirqd, and kswapd. They handle background kernel tasks such as deferred work, interrupt processing, and memory reclaim.

What does while (!kthread_should_stop()) { ... } mean?

It is a common kernel-thread loop pattern. The thread keeps running until the kernel asks it to stop, at which point kthread_should_stop() becomes true.

What permissions do you need to run this program?

If the code is creating kernel threads, it normally must be part of kernel code or a loadable kernel module, which requires elevated privileges to load. A regular unprivileged user cannot just run kernel code from user space.

Can a regular user run kthread_create?

No, not directly. kthread_create is a kernel API, so it can only be used by kernel code such as built-in code or privileged modules.

What happens when the socket system call is used?

The kernel creates a socket object, allocates related kernel structures, and returns a file descriptor to the process. After that the process can bind, connect, listen, send, or receive through that descriptor.

Show a socket example.

A TCP server usually does socket(), bind(), listen(), and accept().
A TCP client usually does socket() and then connect().

Break down setsockopt(server_fd, SOL_SOCKET, SO_REUSEADDR | SO_REUSEPORT, &opt, sizeof(opt)).

setsockopt changes socket behavior. SOL_SOCKET means the option is at the socket layer, and SO_REUSEADDR and SO_REUSEPORT allow address and port reuse behavior that is helpful when restarting servers or sharing listeners, depending on the case.

What happens in the background when socket() is used?

The kernel allocates a new socket structure, associates it with the calling process through a file descriptor, and initializes protocol-specific state. No actual network connection exists yet unless later calls like connect() or accept() happen.

Files, Links, Memory, and Disk Usage

You executed a script, and while it was still running, it got removed. Can it be restored while still running?

Sometimes yes. If the process still has the script file open, you may recover it through /proc/<pid>/fd/ by copying the open file descriptor target.

How do you set or add execute permission only for the owner?

Use chmod u+x file to add execute permission for the owner without changing the other permission bits.
Use chmod 100 file only if you want the file permissions to become owner execute only, because it resets the full permission set to --x------.

What does /proc/<pid>/fd/255 -> '/home/alex/scripts/deploy.sh (deleted)' mean, and is it a soft link or hard link?

It means file descriptor 255 belongs to a running process and points to a file that was already deleted from the filesystem.
The process can still access the file because Linux keeps the file’s inode alive while it is open. The pathname is gone, but the open file object still exists until the process closes it.
The entry under /proc/<pid>/fd/255 is shown as a symlink-like reference to that open file. It is not a normal hard link to the original path.

Soft link vs hard link?

A soft link stores a pathname reference to another file, so it can break if the target is removed. A hard link is another directory entry pointing to the same inode, so it stays valid as long as at least one link or open file reference exists.

How can cat /proc/207/fd/255 succeed if the file was deleted?

Because deletion removes the directory entry, not the open file object itself. If a process still has the file open, the kernel keeps the inode and data available until that last reference is gone.

What is the size of a soft link?

Its size is usually the length of the path it stores. The actual disk usage may vary by filesystem.

What is the size of a hard link?

A hard link is not a separate copy of the file data. It is another name for the same inode, so the file content size is shared.

Show a hard-link and soft-link example.

ln original.txt hardlink.txt creates a hard link, and ln -s original.txt symlink.txt creates a symbolic link. Deleting original.txt breaks the symlink but not the hard link, as long as the inode still exists.

What is the difference between MemFree and MemAvailable in /proc/meminfo?

MemFree is memory that is completely unused right now. MemAvailable is an estimate of how much memory can be used by new applications without heavy swapping, so it is usually the more useful metric.

Show a simple MemFree vs MemAvailable example.

A system may show very low MemFree because Linux uses RAM for cache, but MemAvailable can still be large because that cache can be reclaimed if needed. That is why low MemFree alone does not always mean memory pressure.

What is the difference between paging and swapping?

Paging usually refers to moving memory pages between RAM and backing storage as part of virtual memory management. Swapping often refers more specifically to moving anonymous memory pages out to swap space under memory pressure.

Do operating systems use paging and swapping at the same time?

Yes, modern systems use paging all the time as part of virtual memory, and they may also use swap when needed. The exact behavior depends on workload and kernel settings.

Why do ls and du report different file and folder sizes?

ls -l usually shows the apparent file size in bytes, while du shows disk space actually used in blocks. Sparse files, block size rounding, hard links, and directory metadata can make the numbers different.

I deleted a huge file with rm, but disk usage did not change. Why?

Deleting the filename is not always enough. If a process still has the file open, the data blocks stay allocated until the file descriptor is closed, so the file disappears from the directory but the space is still used.
So this situation often looks like:
  • du says the big file is gone
  • df says space is still used
This is common with logs, databases, and long‑running processes.
In this situation df and du may differ: df shows real filesystem usage, while du only counts visible files. Deleted but still‑open files are not seen by du, but are still counted by df, so df stays high even though the file looks gone.
Follow up: why is this common with logs?
Log writing processes often keep the file open continuously. If you delete the file while the process is still writing to it, the process keeps writing to an unlinked file handle and disk space stays consumed. That is why proper log rotation matters.
Follow up: How do you confirm and fix disk space not freed after deleting a file?
List open files that were deleted by running:
lsof | grep deleted
or to a specific mountpoint (e.g. /data or /)
lsof /path/to/filesystem | grep deleted
This shows processes holding deleted files open. Disk space is freed only when the process closes the file descriptor, so you may need to restart the process, reload the service, rotate logs, or truncate the file safely.
Operational rule: do not delete active logs blindly. Always check which process owns the file first, because space is released only when the last open file handle is closed.

Inodes

What is an inode?

An inode is the filesystem record that stores metadata about a file. It does not store the filename itself. It stores things like the file type, permissions, owner, group, size, timestamps, link count, and pointers to the disk blocks where the file content lives.
The filename lives in a directory entry. That directory entry maps a name, like app.log, to an inode number. This is why the same inode can have more than one filename when hard links are used.

How can you see a file's inode number?

Use ls -i file.txt
The number printed before the filename is the inode number.
You can also use stat file.txt
stat shows the inode number together with permissions, ownership, timestamps, size, and link count.

What happens to the inode when a file is deleted?

Deleting a file removes a directory entry, meaning it removes one filename pointing to the inode. The inode and file data are actually freed only when the link count reaches zero and no process still has the file open.
That is why a deleted log file can still consume disk space if a process keeps writing to it through an open file descriptor.

How are hard links related to inodes?

A hard link is another directory entry pointing to the same inode. Both filenames refer to the same underlying file object. There is no original file from the filesystem's point of view, only multiple names pointing to the same inode.
You can see this with:
ln original.txt alias.txt
ls -li original.txt alias.txt
Both files should show the same inode number and an increased link count.

Why can hard links not cross filesystem boundaries, but symbolic links can?

Hard links cannot cross filesystem boundaries because a hard link is another directory entry pointing to the same inode. Inode numbers are only meaningful inside one filesystem, so a hard link cannot point to an inode that belongs to another partition, mount point, or drive.
This usually fails: ln /mnt/disk1/file.txt /mnt/disk2/file-hardlink.txt
The error is usually something like: Invalid cross-device link
Symbolic links can cross filesystem boundaries because they store a pathname, not a direct inode reference. The target can be on another filesystem, another mount point, or even missing entirely.
This works: ln -s /mnt/disk1/file.txt /mnt/disk2/file-symlink.txt
If the target path disappears, the symbolic link remains but becomes a broken link.

Why can you usually not hard-link directories?

Hard-linking directories is usually restricted because it can create loops in the filesystem tree. Tools like find, backup software, and filesystem checkers rely on the directory tree being mostly acyclic, except for the special . and .. entries.
Symbolic links are used instead when you need one directory path to point to another.

How does it look when two filenames point to the same inode?

A hard link creates another filename that points to the same inode as the original file. Chronologically, it looks like this:
Create a file:
echo "hello from inode land" > original.txt
Check the inode:
ls -li original.txt
Example output:
1234567 -rw-r--r-- 1 alex alex 22 May 11 12:00 original.txt
The first number is the inode number. The 1 after the permissions is the hard-link count, meaning only one directory entry currently points to this inode.
Create a hard link:
ln original.txt alias.txt
Check both files:
ls -li original.txt alias.txt
Example output:
1234567 -rw-r--r-- 2 alex alex 22 May 11 12:00 alias.txt
1234567 -rw-r--r-- 2 alex alex 22 May 11 12:00 original.txt
Both filenames show the same inode number: 1234567.
The link count is now 2, because two directory entries point to the same inode:
original.txt ─┐
├── inode 1234567 -> file data
alias.txt ─┘
Modify one name:
echo "new line" >> alias.txt
Read the other name:
cat original.txt
Example output:
hello from inode land
new line
That happens because original.txt and alias.txt are not two separate copies. They are two names for the same inode and the same file data.
Delete one name:
rm original.txt
Check the remaining one:
ls -li alias.txt
Example output:
1234567 -rw-r--r-- 1 omer omer 31 May 11 12:01 alias.txt
The inode still exists because alias.txt still points to it. The link count dropped back to 1.
