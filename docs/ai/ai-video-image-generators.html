OpenMontage: agentic video-production workflow

OpenMontage is a developer-oriented framework that an external coding agent operates. It combines production instructions, provider integrations, templates, and a review dashboard; it is not a conventional nonlinear video editor and does not replace the coding agent, model runtime, or generation models.
  • Typical flow: research → script → scenes → assets → narration/music → captions → Remotion and FFmpeg render → review and approval.
  • Remotion's role: programmable composition and rendering. Realism comes from stock footage or supplied/generated image and video assets, not Remotion itself.
  • Low-cost first test: Pexels/Pixabay footage, Piper narration, local music, Remotion, and FFmpeg. Add a paid video provider only after the workflow proves useful.
  • Hardware note: its documented local video-generation route expects CUDA/NVIDIA; Apple Silicon is well suited to orchestration, rendering, and narration, while heavy local video generation can run on an NVIDIA server.
