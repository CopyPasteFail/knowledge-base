AI Transcription

Products

KolWrite

KolWrite
What it is: A Hebrew-friendly transcription service for uploaded recordings and direct recording, with speaker separation, searchable transcripts, summaries, and chat over recordings.
Core strengths:
  • Supports 90 languages, including Hebrew
  • Speaker separation and word-level timing
  • Search, summaries, and recording Q&A
Limitations:
  • The free plan is limited to 30 minutes of transcription per month.
  • The product is still maturing, so occasional bugs are possible.

Ivrit.ai

Ivrit.ai
What it is: An open-source Hebrew transcription model and service based on Whisper, with a free web interface and API access.
Core strengths:
  • Hebrew-focused open-source model
  • Free web access and API availability
  • Can power local tools such as Vibe on Windows and macOS
Limitations:
  • More basic features and, in some comparisons, lower transcription quality than KolWrite.

Wispr Flow

Wispr Flow
What it is: A commercial dictation application that turns speech into cleaned-up text in the active application.
Core strengths:
  • Low-friction dictation and contextual formatting
  • Cross-device convenience
Limitations:
  • Transcription is cloud processed; privacy settings can limit stored history but do not make the service fully local.

Voicebox

Voicebox
What it is: An open-source local voice workstation with Whisper transcription, text-to-speech, voice cloning, and API-oriented workflows.
Core strengths:
  • Fully local transcription for privacy-sensitive work
  • Also supports speech generation and voice cloning
  • Useful as a local API or for agents that need spoken output
Typical use cases:
  • Local dictation without a recurring cloud-service dependency
  • Voiceovers, cloned voices, and spoken agent responses
Limitations:
  • More setup and operational responsibility than Wispr Flow.
  • Wispr Flow may still offer better cleanup and usability for everyday dictation.
