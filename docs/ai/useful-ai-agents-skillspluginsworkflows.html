Useful AI Agents Skills/Plugins/Workflows

Big repositories / collections

  • VoltAgent/awesome-agent-skills
    Large cross-agent collection with 1000+ agent skills, compatible with Claude Code, Codex, Gemini CLI, Cursor, and others.
    • https://officialskills.sh/
  • heilcheng/awesome-agent-skills
    Curated list focused on real-world skills used by engineering teams, supporting Claude, Copilot, Codex, Cursor, and Windsurf.
  • anthropics/skills
    Anthropic’s public repo demonstrating skills across technical, creative, and enterprise workflows.
  • microsoft/skills
    Microsoft’s collection covering skills, MCP servers, custom agents, and AGENTS.md templates, includes around 132 skills.
  • vercel-labs/agent-skills
    Focused on practical web and frontend/dev workflows, structured around SKILL.md with optional scripts and references.
  • obra/superpowers
    More of a workflow framework than a raw skill pack, built around composable skills and reusable instructions.
  • openai/skills
    • https://github.com/openai/skills/tree/main/skills/.curated/hatch-pet
      Create, repair, validate, preview, and package Codex-compatible animated pet
  • addyosmani/agent-skills
    Opinionated, production-oriented engineering skills with progressive disclosure via SKILL.md.

  • hoodini/ai-agents-skills

  • JuliusBrussee/caveman
    A Claude Code skill/plugin and Codex plugin that makes agent talk like caveman — cutting ~75% of output tokens while keeping full technical accuracy.
  • alexgreensh/token-optimizer
    Token Optimizer for Claude shows you exactly where every token went, how much each turn cost, which skills and MCP servers actually fired, and which ones are just sitting there eating your budget.
  • heygen-com/hyperframes
    Hyperframes is an open-source video rendering framework that lets you create, preview, and render HTML-based video compositions — with first-class support for AI agents.
    • It is mostly a local HTML-to-video renderer. You write HTML compositions, preview them in a browser, then render them to MP4/MOV/WebM on your own machine or in a container.
    • You only need the skill if you want an AI coding agent to do more of the composition work for you. If you are comfortable writing HTML/CSS/JS yourself, you can use HyperFrames directly through the CLI and studio.
  • SawyerHood/dev-browser
    Browser automation tool for AI coding agents, with a few different ways to run depending on whether you want isolation, Playwright-controlled browser sessions, or to work against your own real browser.
    • Runs browser scripts in a sandboxed QuickJS runtime, so the agent is not just getting raw unrestricted Node.js execution
    • Can work in a more isolated disposable mode when you want safer, cleaner runs without touching your normal browsing session
    • Can also attach to your own browser/tabs, which is useful when you want the agent to continue work inside a real logged-in session instead of a throwaway browser context
  • https://higgsfield.ai/mcp
    Connect Higgsfield to Claude, OpenClaw, Hermes, NemoClaw and generate cinematic images and videos right from your conversations.
  • browsing-skills / browsing-skills
    Make your AI agent call web application actions like APIs, even when the website does not expose the API you need.
    • browsing-skills is an open-source library of website-specific browser actions for AI agents. Each supported website is packaged as a standard SKILL.md skill with focused actions, documented inputs, and structured outputs.

Design references / DESIGN.md resources

Free / Freemium

  • Refero Styles
    Searchable library of curated visual styles for AI-assisted UI work. You can search by brand, mood, color, typography, or URL, then open a style to get colors, typography, spacing, component guidance, design tokens, Tailwind/CSS variables, and a copyable DESIGN.md that a coding agent can use.
    • Best used when you want an AI coding agent to build UI with a specific visual direction instead of default “generic Tailwind SaaS” output.
    • Fits well alongside AGENTS.md, SKILL.md, or project instructions as a design-context file for frontend work.
  • https://www.ui-skills.com/
  • google-labs-code/stitch-skills
    A library of Agent Skills designed to work with the Stitch MCP server. Each skill follows the Agent Skills open standard, for compatibility with coding agents such as Antigravity, Gemini CLI, Claude Code, Cursor.
  • shadcn
    • Skills
    • MCP Server
    • GitHub: shadcn-ui/ui

Paid

  • https://mobbin.com/mcp(Paid)
    Mobbin MCP connects your AI agents to 600,000+ real product screens, so what they build starts with what already works.

My Creations

  • agents-md-builder
    Generate and review repo-local AGENTS.md files for Codex, Claude Code, and other coding agents, using a two-pass workflow that inspects the repo, drafts grounded instructions, and tightens them for safety, commands, and portability
  • postforge
    MCP server + skills for AI-powered content creation. Write posts, generate images, prepare drafts. Works with Claude Code and Codex.
  • evernote-mcp-server
    Python MCP server for Evernote note and notebook operations, built for agent workflows over MCP stdio with safe read-only defaults.
